# Cratis Architecture Documentation

Cratis Architecture is a set of Roslyn analyzers that turn Cratis architectural conventions into build-time diagnostics for .NET codebases. This documentation covers the analyzer package and its rule set.

To add the analyzers to a C# project, follow the [installation instructions](https://github.com/Cratis/Architecture/blob/cf1992389873b80624c14acbd895fba414779772/README.md#installation).

- Understand the conventions the analyzers address with the [code analysis overview](CodeAnalysis/index.md).
- If you have a CRARCH diagnostic ID, find its entry in the [rule reference](CodeAnalysis/Rules/index.md).
